# الدرع الرقمي

موقع توعية تعليمي لمدرسة حوفا المزار الثانوية الشاملة للبنين. يشرح كلمات المرور الضعيفة والتصيّد وتسريب البيانات بتجارب تبقى داخل المتصفح. الواجهة بالعربية ومن اليمين إلى اليسار.

الدرع الرقمي لا يجمع كلمات المرور. لا تكتب كلمة مرور حقيقية في مختبر القوة.

## التشغيل محلياً

يُفضَّل Python 3.11 أو أحدث.

في ويندوز:

```text
py -3 -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
flask --app app run --debug --port 4871
```

ثم افتح http://127.0.0.1:4871. لا حسابات ولا قاعدة بيانات ولا مفاتيح سرية.

## النشر على Render

المستودع على GitHub يجب أن يحتوي `app.py` و`requirements.txt` في الجذر.

1. من [render.com](https://render.com) اختر **New** ثم **Web Service**، واربط مستودع GitHub.
2. استخدم هذه الإعدادات:

| الإعداد | القيمة |
| --- | --- |
| Language | Python 3 |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `gunicorn app:app --bind 0.0.0.0:$PORT` |
| Instance type | Free |

ملف `render.yaml` يحمل الإعدادات نفسها إذا أنشأت الخدمة من Blueprint. بعد كل دفع إلى GitHub يعيد Render النشر تلقائياً.

## السلامة

- حقل كلمة المرور للتجربة فقط. ليس داخل نموذج ولا يُرسل إلى الخادم.
- أمثلة التصيّد رسائل تدريبية خيالية.
- لا تستخدم هذا الموقع لخداع أحد أو إيذائه.

## الاختبارات

```text
pip install -r requirements-dev.txt
pytest
```

اختبارات مختبر كلمة المرور تحتاج Node.js لأنها تشغّل النص البرمجي نفسه الذي تستخدمه الصفحة.
